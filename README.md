# ComfyUI Workflow 出典カタログ

公開Workflowを継続的に発見し、出典と変更履歴を保ったまま制作に利用するためのリポジトリです。収集、実行、品質確認、公開は異なる工程として扱います。

## 長期的に生み出す成果

**世界中の公開ComfyUI Workflowを継続的に取り込み、複数の制作領域で完成作品を生み出し、公開できる共通基盤**を目指す。

次の8領域は**並列の成果目標**であり、番号順に着手する工程ではない。

1. **VRChatワールド**：カフェ、休憩空間、探索ワールドを公開する。
2. **アバター・衣装**：VRM、衣装、アクセサリーを制作・配布する。
3. **BOOTH商品**：3D素材、背景、デジタル商品を公開・販売する。
4. **YouTube・Shorts**：解説動画、短編映像、キャラクター動画を公開する。
5. **Podcast・音声**：音声番組、ナレーション、音響素材を公開する。
6. **映画・アニメーション**：短編映画、連続作品、映像素材を制作する。
7. **3Dモデル**：人物、建築、家具、背景、ゲーム用モデルを制作する。
8. **ゲーム制作**：ゲーム世界、キャラクター、UI、素材を制作する。

VRChat用の小さなカフェは実証対象の一つであり、ほかの領域の開始条件ではない。Workflowの収集・更新と各領域の制作も並列に進める。

共通基盤は、**発見、出典と版の保持、更新検知、再利用、実行、工程統合、結果検証、公開準備**を担う。既存の公開資産を優先し、特定のモデルやサービスへの固定を避ける。

**成功条件**はWorkflowの収集件数ではなく、各領域で公開可能な作品が生まれ、次の作品でも制作工程を再利用でき、必要な手動作業が減ること。公開作品数、完成までの時間、再利用率、再実行の成功率を実測し、数値目標は実績を得てから定める。

未実装の工程を実装済みとは書かない。Workflowの発見、ComfyUIでの素材生成、Unityでの動作確認、VRChatやBOOTHへの公開を別々の完了条件として扱う。

## 守り続ける原則

1. **出典と改訂を記録する。** 元リポジトリ、ファイルの場所、コミット、ファイルのハッシュを保持する。元ファイルが変わっても過去の参照を消さない。
2. **候補を独断で選別しない。** 未分類、未検証、取得失敗、公開終了の情報も状態を明示して残す。検索のための分類を品質評価や順位にすり替えない。
3. **事実と推測を分ける。** ファイル名、人気、ノード名、モデル名だけで動作、品質、互換性を断定しない。実行可能性は実際の環境で別に検証する。
4. **第三者のプログラムを自動実行しない。** 出典収集ではWorkflow、モデル、Custom Node、外部コードを自動でインストール・実行しない。
5. **権利の確認を省略しない。** 公開されていること、利用可能なこと、再配布できること、商用利用できることは同じではない。未確認は未確認と記録する。
6. **生成物の完成を偽らない。** 画像・音声・3D素材の生成成功は、Unityへの取り込み、VRChatでの動作検証、製品化、公開の証拠にならない。それぞれの完成条件を確認する。
7. **復元・追試できる情報を残す。** 通信失敗を候補ゼロと扱わず、入力・出典・改訂・出力の関係を追跡できるようにする。外部成果物は必要なく複製しない。
8. **文書は日本語の確かな原則に限る。** 日付で古くなる順位や作業日誌、推測を含む説明、重複した設計書は置かない。具体的な動作と制約はコードおよびテストで検証する。
