# 超長期ゴールと8つの並列成果

## 最上位の到達状態

公開されているWorkflowを継続して見つけ、8つの制作領域で作品を完成・公開・改善できる基盤を作ります。8つの目標は対等で、達成順序や前提関係は設けません。共通基盤の整備と各領域の制作を並行して進めます。

## 独立した8つの目標

| ID | 制作領域 | 作品例 | 完了の証拠 |
| --- | --- | --- | --- |
| vrchat | VRChatワールド | カフェ、Chill World、交流・探索ワールド | 実機検証と公開ワールドURL |
| avatars | アバター・衣装 | VRM、衣装、アクセサリー | 仕様検証と配布・公開先URL |
| booth | BOOTH商品 | 3D素材、テクスチャ、背景、デジタル商品 | 商品ページURLと利用条件 |
| youtube | YouTube・Shorts | 解説動画、短編、キャラクター動画 | 公開動画URL |
| podcast | Podcast・音声 | 番組、ナレーション、音響素材 | 公開エピソード・音声URL |
| movies | 映画・アニメーション | 短編、連作、映像作品 | 視聴できる完成作品URL |
| models-3d | 3Dモデル | 人物、家具、建築、ゲーム向けモデル | 形式検査と公開・納品の記録 |
| games | ゲーム制作 | プレイ可能なゲーム、世界、キャラクター | 動作確認と公開ビルド・配布先 |

**Chill WorldはVRChatワールドの一種**、ゲーム素材はゲーム・3Dモデルなどの横断用途です。検索タグを増やしても、独立した長期目標を増減させません。

## 8領域で共通する制作サイクル

各領域で作品の仕様を決め、公開Workflowを探し、出典・依存関係・利用条件を確かめてから制作します。生成結果を検証して修正し、作品ごとの完成条件を満たしたら公開します。公開先のURLと公開状態を確認して完了を記録します。

共通化するのは収集、出典追跡、再利用可能な工程、検証記録です。作品の仕様や完成判定は、それぞれの制作先が持ちます。ComfyUIは交換可能な制作手段であって永続的な目的ではありません。

## 成功を測る指標

- 8領域ごとの公開済み作品数、公開URL、完成条件の達成率
- 制作着手から公開までの実時間と人間の手動操作数
- 他領域へ転用できたWorkflow・工程と再実行成功率
- 出典・版・ライセンス・検証証拠が追跡できる割合
- 公開後の修正・再生成に要した作業量

**収集件数、スター数、独自ランキングだけでは成功と判定しません。** 数値目標は実測後に定義し、予測を実績と表記しません。

## 不変の方針

- 8領域を同時並列に扱い、いずれも他の領域のゲートにしない。
- 公開実践を第一に再利用し、独自開発は接続・検証・必要な差分に絞る。
- 必要な生成素材が無いときに、簡易形状、無地の画像、空のシーン、架空の公開記録で埋め合わせない。生成・統合・実機確認・公開の実証が揃わなければ未完成のまま扱う。
- 独自の人気・品質スコアで候補を除外しない。ただし実行時の安全・権利・環境の確認は必要。
- 原典のURL、作者、コミット、ファイルハッシュ、依存関係、利用条件、観測日、実行証拠を保持する。
- 変更に耐えるように仕様、作品、出典台帳、実行環境を分離する。
