# 長期成果と運用原則

## 最終成果

世界中のComfyUI Workflowの進歩を継続的に取り込み、**複数の制作領域で並列に完成作品を生み出し、公開できる制作基盤**を実現する。

Workflowの収集数、人気、独自の評価点は最終成果ではない。完成作品、再利用できた制作工程、制作時間、再現性、維持管理の負担を測る。

## 並列の8成果目標

1. **VRChatワールド**：カフェ、休憩・交流空間、探索ワールドを公開する。
2. **アバター・衣装**：VRM、衣装、アクセサリーを制作・配布する。
3. **BOOTH商品**：3D素材、背景、デジタル商品を公開・販売する。
4. **YouTube・Shorts**：解説動画、短編映像、キャラクター動画を公開する。
5. **Podcast・音声**：音声番組、ナレーション、音響素材を公開する。
6. **映画・アニメーション**：短編映画、連続作品、映像素材を制作する。
7. **3Dモデル**：人物、建築、家具、背景、ゲーム用モデルを制作する。
8. **ゲーム制作**：ゲーム世界、キャラクター、UI、素材を制作する。

番号は優先順位でも実施順でもない。**各分野は独立して着手・制作・検証・公開**する。VRChat用の小さなカフェは実証対象の一つであり、他分野を止める前提条件ではない。

## 共通基盤の到達状態

| 能力 | 長期的な成果 |
| --- | --- |
| 発見 | 公式とコミュニティのWorkflow、Subgraph、Blueprintを継続的に見つける |
| 追従 | 公開元の変更を検知し、版と差分を保存する |
| 再利用 | 出典・依存関係・ライセンスを確認して利用する |
| 実行 | 必要な環境・モデル・Custom Nodeをそろえて動作させる |
| 統合 | 複数の制作工程をつなぎ完成作品へ変える |
| 再現 | 入力、版、環境、出力、失敗原因を追える |
| 公開準備 | 形式、品質、権利、公開先の制約を確認する |
| 改善 | 分野をまたいで制作工程を共有する |

## 変えない原則

- **Workflow収集と8分野の作品制作を並列**に進める。
- 世界中の公開実践を優先し、独自開発は必要な接続部分に限る。
- 独自の点数や人気基準で候補を排除しない。作者の主張と実際の動作結果を区別する。
- 公開元URL、作者、ライセンス、コミット、依存関係を保持する。
- 更新の発見と採用を分離し、未確認のコードやモデルを自動実行しない。
- 特定のモデル、有料API、GPU構成に依存しない交換可能な設計とする。

## 成果指標

公開作品数（分野別／全体）、完成までの実時間、定型工程の手動操作数、Workflow再利用率、更新検知から利用までの時間、固定環境での再実行成功率、公開後の修正回数を記録する。**数値目標は初回制作の実測値に基づいて設定する。**

## 現在地

現在は出典付き収集、静的検査、変更履歴、検索用一覧が実装されている。GPU実行、制作工程の統合、Unity／VRChat SDK連携、販売先・公開先への自動投稿は将来の到達目標である。

**成功条件：** 複数分野で公開可能な完成作品が継続的に生まれ、次回の制作にも同じ基盤を再利用でき、公開Workflowの進歩によって制作能力が継続的に向上すること。
