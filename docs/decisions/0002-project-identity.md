# ADR-0002：過去の名称「Comfy Workflow Atlas」

**状態：ADR-0003により置き換え済み（2026年11月3日）**

過去に表示名「Comfy Workflow Atlas」とリポジトリ名`comfy-workflow-atlas`を検討した。Workflow中心でSubgraph・Blueprintも出典を保って扱う方針は現在も有効である。

**正式名称は`comfyui-workflows-factory`。** [ADR-0003](0003-final-repository-identity.md)を参照。旧名称を現行の案内には使用しない。

名前変更のためにGitの履歴を消したり、リポジトリを再作成したりしない。
