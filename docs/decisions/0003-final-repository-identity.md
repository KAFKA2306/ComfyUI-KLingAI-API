# ADR-0003：正式名称をComfyUI Workflows Factoryとする

**状態：採用（2026年11月3日）。ADR-0002を置き換える。**

- GitHub：`KAFKA2306/comfyui-workflows-factory`
- 表示名：ComfyUI Workflows Factory
- Python配布名：`comfyui-workflows-factory`
- importパス：`gwp`（互換性のため維持）

Workflow中心の収集と将来の作品制作をつなぐ共通基盤として名称を決定する。VRChat、アバター、BOOTH、YouTube、音声、映画、3D、ゲームの成果目標は**並列**とする。

現在の実装は出典付き収集、静的確認、索引生成が中心。未検証のWorkflowの自動実行・採点・公開が完成したとは主張しない。

長期成果は[長期成果と運用原則](../vision.md)を参照。
