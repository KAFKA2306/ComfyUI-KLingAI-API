# ADR-0003: Adopt the GitHub repository name ComfyUI Workflows Factory

Status: accepted (2026-11-03). Supersedes ADR-0002.

- GitHub repository: `KAFKA2306/comfyui-workflows-factory`
- Display name: **ComfyUI Workflows Factory**
- Python distribution: `comfyui-workflows-factory`
- Existing import path: `gwp` (kept for compatibility)

The project keeps a workflow-first, source-preserving inventory of third-party
ComfyUI workflows, blueprints, subgraphs and model references, organized across
image, video, audio, 3D, avatars, VRChat and related use cases.

The term Factory describes the collection and organization pipeline. It does not
claim to automatically execute, grade, install or deploy unverified assets.
Historical repository names remain GitHub redirects and existing Git commits remain intact.
